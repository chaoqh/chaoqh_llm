Differential Expression: Finding Genes That Change

Differential expression (DE) analysis tests whether each gene's expression level differs between conditions (e.g., treated vs. control). The input is a count matrix (genes × samples, integer counts). The output is a ranked list of genes with log2 fold changes, p-values, and adjusted p-values (FDR).

Why Specialized Methods for Count Data?

Counts are not normally distributed

RNA-seq yields integer counts. Variance increases with mean (mean-variance relationship). Standard t-tests assume constant variance and normality — both violated.

Negative binomial distribution

RNA-seq counts follow a negative binomial (NB) distribution: NB(μ, α) where μ = mean, α = dispersion. Dispersion captures biological + technical variability beyond Poisson sampling noise.

Shrinkage stabilizes estimates

With few replicates (n=3), per-gene dispersion estimates are unreliable. DESeq2/edgeR/limma-voom "shrink" gene-wise dispersions toward a fitted trend, borrowing information across genes.

Library size normalization

Samples have different sequencing depths. Normalization (median-of-ratios in DESeq2, TMM in edgeR) computes size factors so counts are comparable across samples.

DESeq2 Workflow (Step by Step)

# 1. Load count matrix and sample metadata
counts <- read.delim("counts_matrix.txt", row.names=1, check.names=FALSE)
coldata <- read.delim("sample_metadata.txt", row.names=1)

# Ensure column order matches
stopifnot(all(colnames(counts) == rownames(coldata)))

# 2. Create DESeqDataSet
library(DESeq2)
dds <- DESeqDataSetFromMatrix(countData = counts,
                              colData = coldata,
                              design = ~ condition)  # formula: condition is the variable of interest

# 3. Pre-filter low-count genes (recommended)
keep <- rowSums(counts(dds) >= 10) >= 3  # at least 10 counts in at least 3 samples
dds <- dds[keep,]

# 4. Run the DESeq pipeline (normalization, dispersion, testing)
dds <- DESeq(dds)

# 5. Extract results for the contrast of interest
res <- results(dds, contrast=c("condition", "treated", "control"))
# contrast = (factor_name, numerator, denominator) → log2FC = treated/control

# 6. Shrink log2 fold changes for visualization/ranking (apeglm recommended)
resLFC <- lfcShrink(dds, contrast=c("condition", "treated", "control"), type="apeglm")

# 7. Order by adjusted p-value
resOrdered <- resLFC[order(resLFC$padj),]

# 8. Save results
write.csv(as.data.frame(resOrdered), "DESeq2_results_treated_vs_control.csv")

Understanding the Results Table

ColumnMeaning
baseMeanMean of normalized counts across all samples
log2FoldChangeLog2 fold change (numerator/denominator). Positive = up in numerator.
lfcSEStandard error of log2 fold change
statWald statistic (log2FC / lfcSE)
pvalueRaw p-value from Wald test
padjBenjamini-Hochberg adjusted p-value (FDR). This is the key column.

Significance threshold: Typically padj < 0.05 (5% FDR). Some studies use padj < 0.05 & abs(log2FoldChange) > 1 (2-fold change) for biological relevance.

Visualization: MA Plot and Volcano Plot

MA Plot

log2 fold change (M) vs. mean expression (A). Shows that low-count genes have high variance (wide spread at left). DESeq2's plotMA(resLFC) highlights significant genes in red.

Volcano Plot

-log10(p-value) vs. log2 fold change. Symmetric "volcano" shape. Significant genes in top corners. Use EnhancedVolcano package for publication-ready plots.

PCA Plot

Principal component analysis of variance-stabilized counts. Shows sample relationships. Replicates should cluster by condition. Outliers visible. Use plotPCA(vst(dds), intgroup="condition").

Heatmap of Top Genes

Expression of top 20–50 DE genes across samples. Use variance-stabilized or rlog-transformed counts. pheatmap or ComplexHeatmap.

Complex Designs

DESeq2 handles complex experimental designs via the design formula:

  • ~ batch + condition: Blocking on batch (batch is a nuisance factor)
  • ~ genotype + treatment + genotype:treatment: Interaction term (does treatment effect depend on genotype?)
  • ~ time + condition + time:condition: Time course with interaction
  • ~ patient + condition: Paired design (patient as blocking factor)

For interactions, use results(dds, name="genotypeB.treatmenttreated") or contrast=list(...).

Independent Filtering

DESeq2 automatically performs independent filtering: genes with low mean counts (low power) are removed from multiple testing correction, increasing power for the remaining genes. The threshold is chosen to maximize the number of rejections. Control with results(dds, independentFiltering=FALSE) to disable.

Common Pitfalls

  1. Using normalized counts (CPM, TPM, FPKM) as input to DESeq2: DESeq2 requires raw integer counts. It does its own normalization internally.
  2. Forgetting to pre-filter: Testing genes with 0–1 counts across all samples wastes multiple testing budget and can cause numerical issues.
  3. Wrong contrast direction: contrast=c("condition", "treated", "control") gives log2FC = treated/control. Swap if you want control/treated.
  4. Ignoring batch effects: If batch is confounded with condition, no statistical fix exists. If not confounded, include in design: ~ batch + condition.
  5. Using padj without checking effect size: A gene with padj=0.04 and log2FC=0.1 (1.07-fold) is statistically significant but biologically negligible. Report both.
  6. Comparing padj across different analyses: padj depends on the set of genes tested. Comparing padj from a 2-group vs. 3-group analysis is not meaningful.
  7. Not checking model assumptions: Plot dispersions (plotDispEsts(dds)), check for outliers (Cook's distance in results).

edgeR Quick Reference

library(edgeR)
y <- DGEList(counts=counts, group=coldata$condition)
keep <- filterByExpr(y)  # automatic pre-filtering
y <- y[keep,,keep.lib.sizes=FALSE]
y <- calcNormFactors(y, method="TMM")
design <- model.matrix(~ condition, data=coldata)
y <- estimateDisp(y, design)
fit <- glmQLFit(y, design)
qlf <- glmQLFTest(fit, coef=2)  # coefficient for condition
topTags(qlf, n=Inf)

limma-voom Quick Reference

library(limma)
library(edgeR)
y <- DGEList(counts=counts, group=coldata$condition)
keep <- filterByExpr(y)
y <- y[keep,,keep.lib.sizes=FALSE]
y <- calcNormFactors(y)
design <- model.matrix(~ condition, data=coldata)
v <- voom(y, design, plot=TRUE)
fit <- lmFit(v, design)
fit <- eBayes(fit)
topTable(fit, coef=2, number=Inf)

Differential Expression Checklist

  • [ ] Raw count matrix (genes × samples) prepared
  • [ ] Sample metadata with condition column matching count matrix columns
  • [ ] Low-count genes filtered (e.g., ≥ 10 counts in ≥ n samples)
  • [ ] DESeq2 (or edgeR/limma-voom) run with correct design formula
  • [ ] Batch effects included in design if present and not confounded
  • [ ] Results extracted with correct contrast direction
  • [ ] Log2 fold changes shrunk (apeglm) for ranking/visualization
  • [ ] MA plot, volcano plot, PCA plot generated and inspected
  • [ ] Significant genes: padj < 0.05 (and optionally |log2FC| > 1)
  • [ ] Results table saved with gene IDs, symbols, baseMean, log2FC, pvalue, padj
  • [ ] Top genes examined for biological plausibility
