What is RNA-seq?

RNA sequencing (RNA-seq) is a high-throughput sequencing technique that captures a snapshot of the transcriptome — the complete set of RNA transcripts in a cell or tissue at a given moment. By sequencing cDNA synthesized from RNA, RNA-seq reveals which genes are expressed, at what levels, and what alternative isoforms exist.

Why RNA-seq Matters

  • Quantitative: Measures expression levels across the entire dynamic range (from a few to millions of transcripts per cell)
  • Comprehensive: Detects known and novel transcripts, splice variants, fusion genes, and non-coding RNAs
  • Unbiased: No prior knowledge of the genome sequence is strictly required (though a reference helps)
  • Versatile: Applicable to bulk tissue, single cells, and even spatial transcriptomics

The RNA-seq Workflow

This site walks through the major steps of a typical bulk RNA-seq analysis pipeline:

  1. Experimental Design — Replicates, controls, sequencing depth, and avoiding batch effects
  2. Quality Control — Assessing raw read quality with FastQC, trimming adapters and low-quality bases
  3. Alignment & Quantification — Mapping reads to a reference genome/transcriptome and counting reads per gene
  4. Differential Expression — Statistical testing for expression changes between conditions (DESeq2, edgeR, limma-voom)
  5. Functional Analysis — Gene ontology, pathway enrichment, and visualization

Key Concepts You Will Learn

Biological Replicates

Independent samples from different biological units (e.g., different mice, different patients). Essential for estimating biological variance. Minimum: 3 per condition.

Count Data Properties

RNA-seq yields integer counts per gene. These are not normally distributed — they follow a negative binomial distribution with mean-variance relationship.

Normalization

Raw counts must be normalized for library size and composition bias before comparison. Common methods: median-of-ratios (DESeq2), TMM (edgeR), TPM/FPKM for within-sample comparison.

Multiple Testing

Testing ~20,000 genes simultaneously requires correction. RNA-seq uses the Benjamini-Hochberg procedure to control the false discovery rate (FDR), typically at 5%.

Prerequisites

  • Basic familiarity with the Unix command line
  • Understanding of central dogma (DNA → RNA → protein)
  • Basic statistics: mean, variance, p-values, hypothesis testing
  • R or Python for downstream analysis (examples use R/Bioconductor)
