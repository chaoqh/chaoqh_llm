Quality Control: Know Your Data Before You Analyze It

Raw sequencing reads contain artifacts — adapter sequences, low-quality tails, PCR duplicates, contamination — that distort downstream analysis. Quality control (QC) identifies these problems so you can fix them (trimming) or flag affected samples.

FastQC: The Standard QC Tool

FastQC (Babraham Institute) generates a per-sample HTML report with ~10 diagnostic modules. Run it on every FASTQ file:

fastqc sample_R1.fastq.gz sample_R2.fastq.gz -o qc_reports/

For many samples, aggregate with MultiQC:

multiqc qc_reports/ -o multiqc_report/

Key FastQC Modules and What They Mean

Per base sequence contentFraction of A/C/G/T at each positionRandom libraries should be flat (~25% each). Bias at start = adapter or priming artifact
Per sequence GC contentGC% distribution across readsShould match expected genome GC%. A second peak = contamination (e.g., adapter, rRNA, bacteria)
Per base N contentFraction of N (unknown) bases at each positionRising N% at ends = quality degradation; trim

RNA-seq Specific QC Considerations

Per-base sequence content is rarely flat

Unlike genomic DNA-seq, RNA-seq shows strong 5′ bias from random hexamer priming and 3′ bias from poly-A selection or degradation. This is expected, not a failure.

Duplication is often biological

In RNA-seq, highly expressed genes (e.g., ribosomal proteins, hemoglobin) produce many identical reads. This is not a PCR artifact. Use Preseq or samtools markdup on aligned reads to distinguish.

rRNA contamination

Even with poly-A selection or rRNA depletion, 5–50% of reads can be rRNA. Check "Overrepresented sequences" for rRNA hits. If > 20% rRNA, consider re-depleting or using a depletion kit.

Strand-specificity check

For stranded libraries, verify the expected strand bias after alignment (e.g., with RSeQC infer_experiment.py). Wrong strandedness setting in quantification = wasted data.

Trimming: Removing Adapters and Low-Quality Bases

Trim every dataset. Even if FastQC shows minimal adapter content, trimmers remove low-quality tails that hurt alignment.

Recommended tools

  • fastp (recommended): Fast, auto-detects adapters, produces HTML/JSON report, does QC + trimming in one step
  • Trimmomatic: Classic, highly configurable, Java-based
  • cutadapt: Flexible, Python, good for custom adapters

Example: fastp

fastp -i sample_R1.fastq.gz -I sample_R2.fastq.gz \
      -o sample_R1.trimmed.fastq.gz -O sample_R2.trimmed.fastq.gz \
      --detect_adapter_for_pe --trim_poly_g --trim_poly_x \
      --qualified_quality_phred 20 --length_required 30 \
      --html qc/fastp_sample.html --json qc/fastp_sample.json

Key options: --detect_adapter_for_pe auto-detects Illumina adapters; --trim_poly_g removes poly-G tails (common on NovaSeq); --trim_poly_x removes poly-X tails; --qualified_quality_phred 20 keeps bases with Q ≥ 20; --length_required 30 discards reads shorter than 30 bp after trimming.

Post-Trimming QC

Always re-run FastQC (or check fastp's HTML report) after trimming. Verify:

  • Adapter content ~0%
  • Per-base quality flat and high across read length
  • No severe length distribution shift (median length should be close to original)
  • Per-base sequence content still shows expected RNA-seq bias (not flat)

RSeQC: Post-Alignment Quality Metrics

Run after alignment (e.g., with STAR) but before quantification:

# Gene body coverage (3' bias detection)
geneBody_coverage.py -r ref.bed -i aligned.bam -o qc/geneBody

# Strand specificity check
infer_experiment.py -r ref.bed -i aligned.bam

# Read distribution (exon/intron/intergenic)
read_distribution.py -r ref.bed -i aligned.bam

# Junction saturation (for splicing analysis)
junction_saturation.py -r ref.bed -i aligned.bam

Interpreting gene body coverage

  • Flat line from 5′ to 3′ = uniform coverage (ideal)
  • Strong 3′ bias = RNA degradation or 3′-tag protocol (QuantSeq)
  • 5′ bias = possible template switching artifact

Sample-Level QC: Flagging Outliers

After QC and alignment, check these per-sample metrics. Flag samples that are extreme outliers (> 2 SD from mean or clear visual outliers in MultiQC):

MetricTypical Range (Mammalian, 30M PE)Concern If
Total raw reads25–35 million pairs< 15M or > 50M (unexpected)
Mapping rate80–95%< 70% (contamination, wrong genome, poor quality)
Uniquely mapped70–90%< 60%
rRNA fraction< 10% (poly-A), < 30% (rRNA-depleted)> 50%
Duplicate rate (post-alignment)20–50%> 80% (possible PCR over-amplification)
Median insert size150–300 bpVery small (< 50 bp) = adapter dimers
Genes detected (> 1 count)12,000–18,000< 8,000 (low complexity or degraded)

Do not automatically discard outliers. Investigate: check metadata, re-examine FastQC, consider biological explanation. Document your decision.

QC Checklist

  • [ ] FastQC run on all raw FASTQ files
  • [ ] MultiQC report generated and reviewed
  • [ ] Adapter content assessed; trimming performed if > 5%
  • [ ] fastp (or Trimmomatic/cutadapt) run on all samples
  • [ ] Post-trimming FastQC/fastp report reviewed
  • [ ] Reads aligned to reference genome
  • [ ] RSeQC run: gene body coverage, strand check, read distribution
  • [ ] Per-sample alignment metrics collected (mapping rate, duplication, genes detected)
  • [ ] Outlier samples identified, investigated, and decision documented
  • [ ] QC summary table created for methods section
